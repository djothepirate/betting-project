## Objectif et autorisation

Livrer intégralement les cinq skills BP validés, l'inventaire, les protocoles, résultats, manifestes et l'extension Lab documentée. ## Périmètre et livrables

Les cinq dossiers `.agents/skills/bp-*`, `docs/skills`, les WO SKL-001/SKL-002/SKL-003 et les index documentaires concernés. Préserver les octets des attestations par des attributs Git ciblés ; ne pas réécrire les hashes historiques. Conserver l'inventaire d'origine et les sources Lab évaluées, avec le dépôt Lab comme source maintenue pour son installation.

La préparation part du main qui contient la fusion INT-001 #11. Une note factuelle dans les synthèses concernées actualise cette base, sans modifier les décisions de campagne ni les preuves INT-001.

## Exclusions

Aucun changement Java, migration, configuration runtime, workflow CI ou fournisseur. Aucun secret ou fichier de clés, transport Lab, campagne, base ou déploiement. Les fichiers temporaires de validation et les worktrees de préparation ne sont pas livrés.
